# Sibling map

iOS gaze math is the Kotlin in `shared/src/commonMain/kotlin/com/vocable/eyetracking/`, linked as `VocableShared.framework`. The web app does not call that framework. It has a TypeScript port under `web/src/tracking/`. Changing one does not change the other.

`GazeTrackingManager.swift` is the iOS camera, dwell, and selection-mode wiring around that Kotlin. It is not a third copy of the math.

`app/` (legacy Android) also contains `KalmanFilter2D.kt`. Leave it alone unless the task is explicitly about Android.

## Presets

`shared/src/commonMain/kotlin/com/vocable/data/PresetData.kt` and `models/Category.kt` are the source. `web/src/data/presets.json` is generated by `node scripts/export-presets.mjs` (also `./gradlew :shared:exportWebPresets` and `npm run sync-presets` in `web/`). Commit the JSON after a preset change. The verify script runs the exporter and restores the file so a mismatch is reported without keeping the rewrite.

## Settings

| iOS | Web |
| --- | --- |
| `iosApp/iosApp/Utils/AppSettings.swift` | `web/src/settings/settingsStore.ts` |

Selection mode strings on both: `none`, `eyeGaze`, `face`, `armRaise`, `handGesture`.

Symbol count on the product is 1–4. Web clamps in `setSymbolCount`. The iOS setter does not. iOS backup import does (`max(1, min(4, v))`). `AppSettingsTests` still allows 2–9.

Phrase packs and ESP32 switches have no web copy.
